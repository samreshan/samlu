Privacy

              

                
Agent activity, snippets, launcher history and optional clipboard history stay on this Mac. API keys are kept in your macOS Keychain.

                
With Whisper or Apple speech, audio never leaves this Mac. With a cloud engine, audio goes only to the provider you chose. Transcripts are kept as text, and audio is never stored.

                
Update checks read a release file from GitHub. Updates are verified against Samlu’s signing key before they are installed.
