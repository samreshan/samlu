About

              
Samlu for macOS

              
A focused AI development kit for speaking instructions, finding developer tools, and knowing when agents finish.

            

          

          

            
Current release boundary

            
This build is macOS only. It supports Claude Code and Codex, Groq or another OpenAI-compatible cloud provider, native macOS notifications, and a developer-focused launcher.

            
Planned companion

            
The iPhone companion and hosted APNs relay come after the Mac build is stable. The planned protocol uses end-to-end encrypted notification content, configurable summaries, and one paired Mac per iPhone.

            
Privacy

            
Agent history, snippets, and optional clipboard history remain local. Voice audio stays on this Mac with on-device engines, or goes only to the cloud provider you choose. Transcript history and API keys stay local; keys are stored in macOS Keychain.
